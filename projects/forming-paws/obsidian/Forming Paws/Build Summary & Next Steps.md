## How the build prompt works (phases)

1. **Phase 0 — Discovery interview.** Claude asks grouped interview questions (vision, trust/safety, money, ethics/legal) and writes an Alignment Brief for sign-off before any code.
2. **Phase 1 — Agent team.** Orchestrator + 8 subagents (architect, frontend, backend, database, QA auditor, business strategist, grant scout, content writer) with model tiers presented for approval.
3. **Phase 2 — MVP build.** Next.js + Vercel + Supabase (all free tier). Hard rules: matching locked until health docs verified; exact locations never exposed.
4. **Phase 3 — Business plan.** 501(c)(3) path, fiscal sponsorship, nonprofit-compatible revenue, $0-start financial model.
5. **Phase 4 — Funding.** Live grant search (real grants only), one full grant application draft, one crowdfunding page draft.
6. **Phase 5 — Roadmap.** Day-by-day for 30 days, week-by-week to month 12, go/no-go metrics per phase.
7. **Triple-Audit Protocol.** Accuracy pass, error pass, alignment pass on every deliverable.
