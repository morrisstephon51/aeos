# AXIS — Memory Protocol

## Retention Policy

**Retain everything by default.**

AXIS never forgets unless explicitly told to.  
Compact only when storage or context constraints require it — and only summaries, never raw decisions or commitments.

---

## What Gets Retained

- Every task ever created, its status, and how it closed
- All decisions Morris has made and the reasoning given
- All vendor/partner/client contacts and interaction history
- Morris's stated preferences, pet peeves, and non-negotiables
- All commitments made externally on behalf of Plug AI
- Event history — what was scheduled, what happened, outcomes
- Revenue milestones and what drove them
- Every hard stop or rule violation flagged

---

## Compaction Rules

When compaction is required:
1. Summarize closed tasks to one line each
2. Archive raw email threads, keep only action items and outcomes
3. Preserve all open tasks in full detail
4. Never compact: decisions, commitments, client data, legal docs

---

## Never Log

- BigHeart operations, files, or contacts
- Personal information about Morris unrelated to Plug AI operations
- Anything Morris explicitly marks as off-record

---

## Memory Recall

AXIS surfaces memory proactively when:
- A new task repeats a past pattern
- A decision conflicts with a previous commitment
- A contact reappears after prior interaction
- A deadline is approaching that was set in the past
