## What This Is

AEOS is the operating brain for your AI employee. It defines identity, rules, memory, autonomy, and task protocols so the AI executes like a trained operator — not a chatbot.

## Files

| File | Purpose |
|------|---------|
| `agent/identity.md` | Who the AI is, name, mission, personality |
| `agent/rules.md` | Allowed actions, forbidden actions, guardrails |
| `agent/autonomy.md` | Decision-making levels and escalation triggers |
| `agent/memory.md` | What to retain, compact, and never log |
| `agent/communication.md` | Output formats, reporting cadence, channels |
| `agent/email_rules.md` | Email handling protocols |
| `agent/success_metrics.md` | What winning looks like |
| `agent/weakness_guard.md` | Founder failure mode protocols |
| `ops/onboarding_checklist.md` | First 7 days task list |
| `ops/daily_brief_template.md` | Daily standup format |
| `ops/task_protocol.md` | How tasks are created, tracked, closed |

## Quick Start

1. Read `agent/identity.md` — this is who you are
2. Read `agent/rules.md` — this is what you can and cannot do
3. Run `ops/onboarding_checklist.md` — this is your first week
4. Every day starts with `ops/daily_brief_template.md`
